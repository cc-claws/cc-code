# TUI 审批面板 UI 改版

状态：已实现，完成本地 TUI 渲染与键盘回归验收。基线：`origin/main`，`bea7a61f`。开发分支：`feat/tui-approval-panel`。

## 目标与范围

按已确认的交互 HTML 原型，提升审批信息的可读性，减少面板留白，以键盘操作为主。只修改 TUI 布局、参数展示、文案与中英文翻译。父/子 Agent 权限、语义门、ACP 选项 ID、确认结果、会话审批记忆与系统提示词均不变。

## 展示要求

- 工具名称、动作说明、执行目录在同一行，例如 `Bash Run command Working directory D:\code\peri`。长标题按显示列宽省略，不重复显示目录。
- Bash 命令默认展开，按终端列宽换行；保留脚本换行与缩进，兼容中文和无空格长串。禁止 `command=` 摘要和“完整命令”展开按钮。
- 当前 Edit 显示文件路径及原内容/新内容对比，删除用 `−`、新增用 `+`，公共上下文保留。批量中的其他 Edit 保留路径和额外参数，切换到该项后展示对比。其他工具展示实际参数，不只展示一个字段。
- 只保留一组当前工具的三项选择：同意本次、本次会话同意、拒绝。选中项用方向标记与高亮；待提交工具不出现执行成功的 `✓`。
- 宽屏将说明与选项同行；窄屏在三项下方显示当前选项的说明。命令会话提示：`本次会话内，相同命令不再询问` / `Don’t ask again for this command in this session`。文件操作使用对应文件提示。
- 批量工具展示各工具与各项当前选择，独立显示当前工具位置、三种选择的数量；切换工具后保留各项选择。
- 取消额外确认按钮、重复说明、无意义空行；原型测试按钮只属于 HTML，不进入 TUI。

## 键盘与高度

- `↑↓` 仅选择当前工具的审批项，边界停留；`Tab` / `Shift+Tab` 切换工具；`Enter` 提交；`Esc` 全部拒绝。现有按键处理及审批结果不变。
- 可操作终端尺寸下，底部始终显示一组快捷键提示；没有内部滚动条，不用方向键滚动参数。极小尺寸不足以容纳所有控件时只保证不 panic。
- 根据实际换行后的内容计算高度，短命令自然收紧，长内容按现有底部面板可用高度展开。超高时优先保留当前工具信息、三项选择与快捷键。
- 用户已确认极长脚本处理：无滚动；明确提示剩余未显示行数及扩大终端。批量内容无法同时容纳时优先展示当前工具，保持位置和数量信息。

## 验收

1. 中英文短 Bash：工具/动作/目录同行，完整命令下一行；仅三个选项，无重复确认按钮。
2. 长 Bash、多行脚本、中文路径、无空格长串：按显示列宽换行，保留缩进，无内部滚动。
3. 极长脚本与矮终端：存在明确剩余行提示，三项选择和底部按键提示可见。
4. Edit：文件路径、公共上下文、删除及新增内容可区分。
5. 批量 3 项及 10 项：仅一组审批选项，计数区分本次/会话/拒绝，切换后选择不丢失。
6. 键盘选择与参数展示互不争用；确认、拒绝、会话选项 ID 与原逻辑一致。
7. 终端控制序列不能污染布局；空列表、窄终端与极小尺寸不 panic。

验证以真实 Ratatui headless 渲染和现有键盘处理为依据；HTML mock 结果不作为真实审批执行证据。
