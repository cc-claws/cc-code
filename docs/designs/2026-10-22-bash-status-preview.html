Bash 执行状态渲染 · TUI 效果稿

对应 docs/prd/bash-execution-status-alignment.md 的 5.5 展示规格。 本页是设计稿，不是真实 TUI 截图；颜色按暗色主题近似取值。

● 运行 / 排队 / 审批（闪烁） ● 成功 ● 失败 ● 后台运行 ⎿ 结果区前缀（宽 5 列，续行 5 空格悬挂）

场景 A · 多工具逐个审批

Queued + AwaitingApproval
● Bash(cmd A) ⎿ Waiting for permission… ● Bash(cmd B) ⎿ Waiting… (ctrl+b to run in background) ● Bash(cmd C) ⎿ Waiting… (ctrl+b to run in background)
正在审批的工具显示 Waiting for permission…，尚未轮到的显示 Waiting…；两者都不带计时。

场景 A2 · jev 自动判定（单工具）

Queued · auto gate
● Bash(git status) ⎿ Waiting… (ctrl+b to run in background)
语义门在后台调用 LLM judge，不弹窗、不需要用户操作，所以显示 Waiting…；判定 Allow 后直接转 Running…，只有 Ask 才弹人工审批。

场景 A3 · Bypass（直接放行）

no gate
● Bash(git status) ← 同批完成 Pending→Start，不显示 Waiting…
Bypass 与 Auto 共用同一套状态机；不人为延时、不强制插帧。跨批次时自然闪一帧 Waiting…，同批次直接进入 Running。

场景 B · 单工具审批（HITL）

AwaitingApproval
● Bash(npm run build) ⎿ Waiting for permission…
人工审批弹窗打开时显示；批准后转 Running…，拒绝则直接进入失败态，不回退到排队。

场景 C · 已开始执行，未满 2 秒

Running < 2s
● Bash(sleep 3)
只有工具头与闪烁指示器；2 秒内完成则永远不会出现 Running…。

场景 D · 满 2 秒且无输出

Running ≥ 2s
● Bash(sleep 3) ⎿ Running… (2s) (ctrl+b to run in background)
Ctrl+B 提示在 Running… 之后，用 5 空格悬挂缩进；未传 timeout 时不显示 timeout 段。

场景 E · 运行中已有输出（L3）

Running + tail
● Bash(npm run build) ⎿ vite v5.0.0 building for production… transform 1203 modules… rendering chunks… dist/index.js 120.31 kB dist/index.css 8.42 kB … +12 lines (22s · timeout 5m) (ctrl+b to run in background)
只显示最后 5 个视觉行；状态行只剩 (22s · timeout 5m)，不再带 Running… 前缀；timeout 仅模型显式传参时出现。

场景 F · 完成且有输出

Finished
未传 timeout
● Bash(npm run build) ⎿ vite v5.0.0 building for production… transform 1203 modules… rendering chunks… … +45 lines (ctrl+o to expand)
显式传了 timeout（90s）
● Bash(cd "D:/code/nt_order" && php storage/probes/probe_t57489_prodlog.php 2>&1 | head -25) ⎿ order_status_history_000 总行数: 3323926 order_status_history_000 今日行数: 4015 … +11 lines (ctrl+o to expand) ⎿ (timeout 1m 30s)
非详细模式显示前 3 行并追加展开提示；详细模式（Ctrl+O）全量显示。传了 timeout 时底部追加独立一行 ⎿ (timeout 1m 30s)，不是悬挂缩进。

场景 G · 完成且无输出

Finished · empty
● Bash(true) ⎿ Done
不再转圈。详细模式显示 (No output)。

场景 H · 失败

Failed
● Bash(npm run build) ⎿ error TS2304: Cannot find name 'foo'. … +2 lines (ctrl+o to expand)
指示器与输出均为 error 色；退出码非零且无 stderr 时沿用现有错误摘要行。

场景 I · 已后台化

Backgrounded
● Bash(long-task) ⎿ Running in the background (↓ to manage) ⎿ (timeout 5m)
后台化后不再显示 Running… 与计时；timeout 行仅在显式传参时出现。

场景 K · 窄终端折行

wrap
● Bash(npm run build -- --mode production --out-dir dist --sourcemap) ⎿ Running… (22s · timeout 5m) (ctrl+b to run in background)
命令摘要折行时续行缩进到命令起始列（7 列）；结果区内容折行使用 5 空格悬挂缩进，CJK 按 2 列计算。

场景 L · 详细模式（Ctrl+O）

detail mode
● Bash(npm run build -- --mode production --out-dir dist) ⎿ (ctrl+b to run in background) ⎿ vite v5.0.0 building for production… transform 1203 modules… rendering chunks… dist/index.js 120.31 kB dist/index.css 8.42 kB dist/vendor.js 512.00 kB built in 21.4s (22s · timeout 5m)
命令完整折行、输出全量显示（不截断 5 行）；完成后同样显示全量输出。

场景 M · 执行中断

interrupted
● Bash(long-task) ⎿ interrupted by user
Esc / Ctrl+C 后进入 Finished(Failed)，运行行、计时与 Ctrl+B 提示全部消失；同批其他已完成工具保留原结果。

场景 N · 并发多工具

join_all
● Bash(cmd A) ⎿ Running… (2s) (ctrl+b to run in background) ● Bash(cmd B) ⎿ Running… (1s) (ctrl+b to run in background)
每个工具独立计时、独立提示；渲染顺序按 tool_use 原始顺序，不随完成先后重排。

扩展用例 · 审批边界

reject / cancel
O · 审批拒绝
● Bash(rm -rf build) ⎿ User rejected
P · 审批取消（Esc）
● Bash(npm run build) ⎿ Cancelled
拒绝与取消都直接进入 Finished(Failed)，不回退到 Waiting，也不继续执行。

扩展用例 · 计时边界

duration format
Q · 跨分钟
● Bash(npm run build) ⎿ Running… (1m 5s · timeout 5m) (ctrl+b to run in background)
R · 跨小时（未传 timeout）
● Bash(npm test) ⎿ Running… (1h 2m) (ctrl+b to run in background)
秒数 < 60 显示 Ns；≥ 60 显示 Nm Ns；≥ 1 小时显示 Nh Nm。timeout 仍只在显式传参时出现。

扩展用例 · 运行中输出形态

ANSI / JSON
S · ANSI 颜色保留
● Bash(npm test) ⎿ ✓ auth.spec.ts (2.1s) ✗ cart.spec.ts (0.8s) … +18 lines (12s · timeout 5m) (ctrl+b to run in background)
T · JSON 美化
● Bash(curl -s localhost:8080/status) ⎿ { "status": "ok", "uptime": 3600 } (3s) (ctrl+b to run in background)
运行中 tail 与完成态共用同一套 OutputLine 装饰器：ANSI 保留、JSON 美化、URL 着色、折行口径一致。

扩展用例 · 混合状态

mixed phases
● Bash(cmd A) ⎿ done output ● Bash(cmd B) ⎿ Running… (2s) (ctrl+b to run in background) ● Bash(cmd C) ⎿ Waiting… (ctrl+b to run in background)
同一条回复里可以同时出现已完成、运行中、排队三种工具块；每个工具独立维护 phase 与计时。

扩展用例 · 子 Agent 抽屉

subagent
└─ Agent(扫描日志) ● Bash(grep -r ERROR logs/) ⎿ Running… (3s)
抽屉内同样按 phase 渲染，但子 Agent 没有后台化入口，不显示 Ctrl+B 提示。

扩展用例 · 历史恢复与非 Bash

restored / non-bash
W · 历史恢复
● Bash(npm run build) ⎿ built in 2.1s
X · 非 Bash 工具
● Read(src/main.rs) ⎿ Read 120 lines
历史恢复一律 Finished，无运行行/计时/提示；非 Bash 工具只受益于 Finished 语义（空输出显示 Done），不新增运行态行。

扩展用例 · 大输出与极窄终端

scale / narrow
Y · 十万行输出（运行中估算）
● Bash(seq 1 100000) ⎿ 99996 99997 99998 99999 100000 ~100000 lines (2s) (ctrl+b to run in background)
Z · 40 列窄终端
● Bash(npm run build --prod) ⎿ Running… (2s) (ctrl+b to run in background)
大输出只保留尾部 5 行并显示 ~N lines 估算；窄终端下状态行与提示按显示宽度折行，续行保持悬挂缩进。

时间线 · 一条执行 3 秒的 Bash（无审批、无输出）

sleep 3
t = -50ms（ToolPending + ToolStart 同批到达）
● Bash(sleep 3)
t = 0s（ToolStart）
● Bash(sleep 3)
t = 1s
● Bash(sleep 3)
t = 2s（命中 2 秒阈值）
● Bash(sleep 3) ⎿ Running… (2s) (ctrl+b to run in background)
t = 3s（ToolEnd）
● Bash(sleep 3) ⎿ Done
Running… 只出现约 1 秒（2s–3s）；2 秒内完成则一次都不出现。

时间线 · 有审批（jev / HITL）

sleep 3 · approval
t = 0ms（ToolPending）
● Bash(sleep 3) ⎿ Waiting… (ctrl+b to run in background)
t = 80ms（审批弹窗打开）
● Bash(sleep 3) ⎿ Waiting for permission…
t = 1.2s（批准 → ToolStart）
● Bash(sleep 3)
t = 3.2s（ToolStart + 2s）
● Bash(sleep 3) ⎿ Running… (2s) (ctrl+b to run in background)
t = 4.2s（ToolEnd）
● Bash(sleep 3) ⎿ Done
计时从 ToolStart（1.2s） 起算，不是从 ToolPending 起算。

时间线 · jev 自动判定（git status）

auto gate
t = 0ms（ToolPending）
● Bash(git status) ⎿ Waiting… (ctrl+b to run in background)
t = 120ms（judge 调用中，无弹窗）
● Bash(git status) ⎿ Waiting… (ctrl+b to run in background)
t = 900ms（Allow → ToolStart）
● Bash(git status)
t = 1s（命令完成）
● Bash(git status) ⎿ On branch main nothing to commit, working tree clean
判定耗时等于一次 LLM judge 往返；Allow 不弹窗，只有 Ask 才进入人工审批并显示 Waiting for permission…。

时间线 · 有持续输出（L3）

for i in 1 2 3
t = 0s（已有 line 1，但 < 2s）
● Bash(for i in 1 2 3; …)
t = 1s（已有 line 2，仍 < 2s）
● Bash(for i in 1 2 3; …)
t = 2s（命中阈值，显示尾部）
● Bash(for i in 1 2 3; …) ⎿ (ctrl+b to run in background) ⎿ line 1 line 2 (2s)
t = 3s（ToolEnd）
● Bash(for i in 1 2 3; …) ⎿ line 1 line 2 line 3
2 秒阈值对输出尾部同样生效：2 秒内即使已有输出也只显示 header，避免短命令刷屏。

对照 · 现状 vs 目标

Before / After

现状（peri 当前）

● Bash(sleep 3) ⎿ Running… (2s) ● Bash(true) ← 已完成但仍在转圈
无排队/审批行、无运行中输出、timeout 永不显示、空输出完成后仍转圈。

目标（本 PRD）

● Bash(cmd B) ⎿ Waiting… (ctrl+b to run in background) ● Bash(npm run build) ← 显式传了 timeout=300000 ⎿ Running… (2s · timeout 5m) (ctrl+b to run in background) ● Bash(true) ⎿ Done
排队态、审批态、运行中输出尾部、timeout（仅显式传参）、空输出完成态全部补齐。
